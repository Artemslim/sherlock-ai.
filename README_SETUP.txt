SHERLOCK AI v0.8 — автоматический поиск публичных упоминаний номера

Что добавлено:
- Серверная функция Netlify вызывает Brave Search API.
- API-ключ хранится в переменной окружения Netlify, а не в публичном JavaScript.
- Результаты поиска (название, описание, URL) показываются в интерфейсе.

ОБЯЗАТЕЛЬНО перед использованием:
1. Создай/получи API key в Brave Search API: https://brave.com/search/api/
2. В Netlify открой проект → Site configuration (или Project configuration) → Environment variables.
3. Добавь переменную:
   Key: BRAVE_SEARCH_API_KEY
   Value: твой ключ Brave Search API
4. Сохрани переменную и сделай новый deploy, чтобы функция получила настройки.
5. В Deploys загрузи содержимое этого ZIP в существующий проект. В ZIP есть папка netlify/functions и файл netlify.toml; они обязательны.
6. Проверь номер. Если ключ не настроен, интерфейс покажет понятную ошибку.

Важно:
- Сам по себе архив не содержит API-ключа и не может выполнять реальный поиск без него.
- Не вставляй ключ в app.js или index.html.
- Поиск показывает только публично индексируемые страницы и не доказывает, что номер принадлежит конкретному человеку.
